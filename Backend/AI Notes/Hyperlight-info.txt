HYPER LIGHT DRIFTER SAVE FIELD INFORMATION

Purpose:
This file describes observed Hyper Light Drifter save fields from decoded save data.
This is not confirmed official documentation. These are educated guesses based on field names, values, and patterns.
Use this file to evaluate whether edited values match the expected type, format, and general behavior.

General save structure:
- The decoded save appears as a JSON object.
- Many simple fields are numeric flags, counts, timers, coordinates, or IDs.
- Some fields are compact custom strings using separators such as +, =, &, and >.
- Do not assume all string fields are normal text. Many are encoded lists.
- Empty strings may be valid for fields that store lists of collected/completed data.
- Numeric 0/1 fields should usually remain numeric 0 or 1, not true/false.
- Unknown compact string formats should usually be preserved unless the user understands them.

GENERAL VALUE RULES

Numeric flag:
- Expected values: 0 or 1.
- Suspicious values: true, false, text, decimals, negative numbers, values above 1.

Integer count:
- Expected values: whole numbers, usually 0 or positive.
- Suspicious values: text, booleans, decimals when field normally uses integers, negative values unless original field uses negatives.

Decimal/stat value:
- Expected values: numbers, may include decimals.
- Suspicious values: text, booleans, empty values.

Coordinate:
- Expected values: numbers.
- Suspicious values: text, booleans, empty values, extremely large values.

Compact list string:
- Expected values: string with separators such as +, =, &, >
- Suspicious values: boolean, plain number, random text, malformed separators, missing ending separator if original had one.

Unknown custom string:
- Expected values: preserve original format.
- Suspicious values: changed type, emptying non-empty data, changing separator structure.
