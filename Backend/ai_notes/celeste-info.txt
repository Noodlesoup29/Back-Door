CELESTE .celeste schema for edit checking. Use as context, not fixed risk scores.

Format: XML 1.0 file, root SaveData. Top-level values are global/profile data. SaveData.Areas contains chapter-specific progress; preserve Areas unless supporting advanced chapter edits.

General invalid patterns:
- boolean -> anything except lowercase true/false
- integer -> decimal, text, bool, empty, negative unless expected
- FileTime duration -> non-negative integer; milliseconds = value / 10000
- list/object element -> replacing with plain text, deleting child structure
- attribute-only element -> deleting/renaming attributes, invalid IDs/modes

Top-level fields:
Version: string, game version. Usually leave unchanged; suspicious if empty/random.
Name: string, save name. Suspicious: empty, very long, XML-breaking chars.
Time: non-negative integer FileTime duration. Suspicious: negative, decimal, text, bool, impossible huge/small.
LastSave: timestamp string. Usually leave unchanged; suspicious if invalid/empty/random.
CheatMode: boolean true/false.
AssistMode: boolean true/false; related to Assists.
VariantMode: boolean true/false; related to Assists.
TheoSisterName: string, default Alex. Suspicious: empty/very long/XML-breaking chars.
UnlockedAreas: non-negative integer, plausible chapter count. Suspicious: negative, decimal, text, bool, extremely high.
TotalDeaths: non-negative integer.
TotalStrawberries: non-negative integer; should be plausible vs Areas strawberry data.
TotalGoldenStrawberries: non-negative integer; should be plausible vs Areas.
TotalJumps: non-negative integer.
TotalWallJumps: non-negative integer.
TotalDashes: non-negative integer.
RevealedChapter9: boolean true/false.

Assists object: do not replace whole object with text.
Assists.GameSpeed: integer. Suspicious: negative, decimal, text, bool, huge.
Assists.Invincible: boolean.
Assists.DashMode: string enum. Known/default: Normal. Suspicious: empty, number, bool, random unknown mode.
Assists.DashAssist: boolean.
Assists.InfiniteStamina: boolean.
Assists.MirrorMode: boolean.
Assists.ThreeSixtyDashing: boolean.
Assists.InvisibleMotion: boolean.
Assists.NoGrabbing: boolean.
Assists.LowFriction: boolean.
Assists.SuperDashing: boolean.
Assists.Hiccups: boolean.
Assists.PlayAsBadeline: boolean.

Structured fields:
Flags: list of string event flags affecting story/dialogue. Preserve list; suspicious if replaced/deleted or random unknown strings.
Poem: list of string Crystal Heart abbreviations. Known: fc,fcr,os,osr,cr,crr,cs,csr,t,tr,tf,tfr,ts,tsr,mc,mcr. Suspicious: unknown abbreviations, non-list, numbers/bools.
SummitGems: exactly 6 boolean values. Suspicious: not 6 values, non-booleans, replaced with text.
LastArea: attribute-only element. Attributes: ID integer-like, Mode string such as Normal, sometimes SID. Suspicious: missing attrs, text content, negative/invalid ID, unknown Mode.
Areas: list of AreaStats chapter data. Contains completion, deaths, strawberries, hearts, cassettes, times, modes. Preserve unchanged for global editor.
EntityID: collectible/key identifier with KEY attribute. Suspicious: missing KEY or replacing structure with text.

Example observed save: Version 1.4.0.0, Name Madeline, Time 764888480000, LastSave 0001-01-01T00:00:00, modes false, TheoSisterName Alex, UnlockedAreas 10, TotalDeaths 3731, TotalStrawberries 172, TotalGoldenStrawberries 0, TotalJumps 29162, TotalWallJumps 5780, TotalDashes 24334, RevealedChapter9 true, LastArea ID 1 Mode Normal.
