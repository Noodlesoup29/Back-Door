UNDERTALE file0 schema for edit checking. Use as context, not fixed risk scores.

Format: plain text save, one value per line. Line order matters. Never add, delete, or reorder lines. Numeric fields are stored as text but should behave as numbers. Unknown "Line X" fields should usually stay unchanged.

General invalid patterns:
- integer field -> text, boolean, decimal, empty, symbols
- 0/1 field -> anything except 0 or 1
- ID field -> unknown ID, text, boolean, decimal, negative, empty
- unknown line changed -> suspicious, especially type/size/structure changes

Known file0 fields:
1 Save Name: string, short player name. Suspicious: empty, very long, control/special chars.
2 LV: integer 1-20. Suspicious: <=0, >20, decimal, text, boolean.
3 Max HP: integer, usually 1-99. Suspicious: <=0, >99 unusual, >111 very unusual, decimal/text/bool.
5 Attack: non-negative integer. Suspicious: negative, decimal, text, bool, huge.
6 Weapon Attack: non-negative integer. Related: Weapon. Suspicious: negative, decimal, text, bool, huge.
7 Defense: non-negative integer. Suspicious: negative, decimal, text, bool, huge.
8 Armor Defense: non-negative integer. Related: Armor. Suspicious: negative, decimal, text, bool, huge.
11 Gold: non-negative integer. Suspicious: negative, decimal, text, bool, empty.
12 Kills: non-negative integer. Progression/route-sensitive. Suspicious: negative, decimal, text, bool, huge route-changing edits.
29 Weapon: integer ID. Valid: 3 Stick, 13 Toy Knife, 14 Tough Glove, 25 Ballet Shoes, 45 Torn Notebook, 47 Burnt Pan, 49 Empty Gun, 51 Worn Dagger, 52 Real Knife. Suspicious: unknown ID, wrong type.
30 Armor: integer ID. Valid: 4 Bandage, 12 Faded Ribbon, 15 Manly Bandanna, 24 Old Tutu, 44 Cloudy Glasses, 46 Stained Apron, 48 Cowboy Hat, 50 Locket, 53 Genocide Locket, 64 Temmie Armor. Suspicious: unknown ID, wrong type.
36 Fun Value: integer 1-100. Suspicious: outside 1-100, decimal, text, bool.
531 Asriel Fight Mode: 0/1 fight flag. Usually leave unchanged. Suspicious: any non-0/1 or changing without context.
548 Room Number: integer room ID. Progression-sensitive. Suspicious: wrong type, negative, unknown room, mismatch with story flags.

Known room IDs: 1-3 Dog error rooms, 4 Start, 19 Napstablook, 20 Spider shop, 41 Toriel fight, 44 Snowdin start, 49 Doggo, 57 Dogi, 75 Garage, 77 Papyrus room, 81 Papyrus fight, 103 Piano reward, 115 Mad Dummy, 121 Mettaton house, 128 Tem Village, 134 Undyne, 141 Alphys lab, 160 So Sorry, 165 Royal Guard, 177 Muffet, 211 Mettaton, 237 Asgore/Asriel, 244 True Lab, 248 Memoryhead, 252 Reaper Bird, 256 Lemon Bread, 260 Endogeny.
