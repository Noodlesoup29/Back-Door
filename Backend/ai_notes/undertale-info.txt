UNDERTALE FILE0 SAVE FIELD INFORMATION

Purpose:
This file describes known Undertale file0 fields so BackDoor can evaluate user edits.
Do not treat this file as a fixed risk list. Use it as schema/context.
Risk should be generated by comparing the user's changed value to the expected type, range, and behavior of the field.

General format:
- file0 is a plain-text, line-based save file.
- Each line stores one value.
- Line numbers are meaningful.
- Do not reorder, add, or delete lines.
- Unknown lines should be preserved exactly.
- Values are usually strings or integers.
- Many numeric fields are stored as text in the file, but semantically they should be treated as numbers.

Important:
If a field expects an integer and the user changes it to text, boolean, decimal, empty value, or symbols, that edit should be considered risky.
If a field expects a boolean-like 0/1 value and the user enters anything other than 0 or 1, that edit should be considered risky.
If a field expects a known ID and the user enters an unknown ID, that edit should be considered risky.

Name pattern: Line X

UNDERTALE.INI CONTEXT
- undertale.ini is separate from file0.
- undertale.ini can affect menu or meta values.
- Editing undertale.ini alone may not change actual gameplay values stored in file0.
- A known Flowey-related section is:
  [FFFFF]
  F="1.000000"
- Flowey-related edits should be treated as progression/fight-state edits, not simple stat edits.

RISK EVALUATION GUIDANCE
When evaluating a user edit, consider:
1. Did the value's type change?
   Example: integer field changed to true, false, text, or empty value.
2. Is the value outside the expected range?
   Example: LV changed to 999.
3. Is the value an unknown ID?
   Example: Weapon changed to 999.
4. Is the field route/progression-sensitive?
   Example: Kills, Room Number, Asriel Fight Mode.
5. Is this an unknown line?
   Example: Line 260 changed from 0 to "hello".
6. Does the new value conflict with related fields?
   Example: Weapon changed but Weapon Attack does not match expected behavior.
